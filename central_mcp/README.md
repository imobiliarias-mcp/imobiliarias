# Central Rental Research MCP Server (Python)

Servidor Model Context Protocol (MCP) central para pesquisa de aluguéis nas 15 imobiliárias e portais do Vale do Aço e nacionais.

## Funcionalidades
* Construído com o SDK oficial `mcp` (FastMCP).
* Suporte nativo a transportes `stdio`, `sse` e `streamable-http`.
* Integração padronizada com 15 imobiliárias via Object Calisthenics e SOLID.
